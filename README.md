# 🔥 Sapucaia Roleplay Oficial

Bot oficial do Discord do Sapucaia Roleplay.

## 🚀 Funções

- Status automático do FiveM
- Jogadores online
- Limite de jogadores
- ONLINE/OFFLINE
- Atualização automática
- Contador para restart
- Botão CONECTAR
- Botão LOJA
- Painel de configuração
- Configuração pelo Discord
- Sistema de permissão por cargo

## 🎮 Comandos

/status

/config

## ⚙️ Configuração

O painel pode ser configurado diretamente pelo Discord.

## 👑 Developer

Apenas o cargo com o ID configurado no `settings.json` pode utilizar o painel de configuração.
